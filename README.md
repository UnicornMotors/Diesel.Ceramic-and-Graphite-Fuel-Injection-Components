# Diesel.Ceramic-and-Graphite-Fuel-Injection-Components
A major problem with modern diesel engines, is the sensitivity of the fueling system to unclean or contaminated fuel. Things like debris or water in the fuel can destroy the system! Even IDI fuel pumps like the Stanadyne can get corroded by too much water in fuel. But we want to run impure &amp; waste oil fuels.
