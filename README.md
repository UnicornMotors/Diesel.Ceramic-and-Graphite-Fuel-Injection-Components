# Diesel.Ceramic-and-Graphite-Fuel-Injection-Components
A major problem with modern diesel engines, is the sensitivity of the fueling system to unclean or contaminated fuel. Things like debris or water in the fuel can destroy the system! Even IDI fuel pumps like the Stanadyne can get corroded by too much water in fuel. But we want to run impure & waste oil fuels, with minimum processing steps. For example: SVO = straight vegetable oil

# Solution: Use Ceramics!
A Permanent Solution is to make all fueling component in contact with the oil out of Ceramics, Ceramic-matrix Composite, Graphite, and advanced engineering materials! Also corrosion-resistant metals can be used for some, easier to replace components.

If you've seen toy stirling engines made with a glass tube for a cylinder and Graphite piston? That is the same concept. We can use a Ceramic cylinder & Graphite pison on the IDI Fuel Injection Pump, or common rail diesel pump. This would never corrode! Ceramic is also very hard, and it can handle many scenarios where a metal pump would fail.
